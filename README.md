# IronKaggle Store Sales Forecasting

A store sales forecasting project for the Ironhack AI Engineering bootcamp IronKaggle competition.

The project uses a Random Forest model and out-of-fold (OOF) store-level features designed to avoid target leakage. The Random Forest achieved an R² of 0.9886 on a held-out validation split. This is a local validation result, not the competition's hidden-test score.
